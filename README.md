# Nvidia App Cleaner

用于清理 NVIDIA App 遗留的驱动安装包和缓存，释放系统盘空间。

- 按版本选择并删除旧驱动安装包
- 可选清理 `Installer2` 和 NGX
- 修复安装包丢失后下载卡在 100% 的问题

清理或修复前请退出 NVIDIA App。

---

Removes driver packages and caches left by NVIDIA App to free system drive space.

- Select and remove old driver packages by version
- Optionally clean `Installer2` and NGX
- Repair downloads stuck at 100% after an installer is deleted

Exit NVIDIA App before cleanup or repair.
